# Upstream firmware links

Firmware source and binaries are not redistributed in this repository. Download them from DuPPa's upstream project:

- [Firmware directory, pinned revision](https://github.com/DuPPadotnet/I2CEncoderV2.1/tree/d47fd5afe6d1130eee8f7d02c4856071b2adc8be/Firmware)
- [MPLAB X source project](https://github.com/DuPPadotnet/I2CEncoderV2.1/tree/d47fd5afe6d1130eee8f7d02c4856071b2adc8be/Firmware/I2CEncoderV2.1.X)
- [REV2.3 production HEX](https://github.com/DuPPadotnet/I2CEncoderV2.1/blob/d47fd5afe6d1130eee8f7d02c4856071b2adc8be/Firmware/Binary%20file%20REV2.3/I2CEncoderV2.1.X.production.hex)
- [REV2.1 production HEX](https://github.com/DuPPadotnet/I2CEncoderV2.1/blob/d47fd5afe6d1130eee8f7d02c4856071b2adc8be/Firmware/Binary%20file%20REV2.1/I2CEncoderV2.1.X.production.hex)
- [Current upstream firmware](https://github.com/DuPPadotnet/I2CEncoderV2.1/tree/master/Firmware)

Pinned upstream commit: `d47fd5afe6d1130eee8f7d02c4856071b2adc8be`.

DuPPa declares the firmware GPLv3, but `main.c` and generated drivers also contain Microchip-product-only notices. Linking to upstream avoids republishing that unresolved licensing combination. The project-wide GPL declaration does not replace individual third-party notices. No claim is made here that the published source reproduces either HEX image.

For programming instructions, see the [encoder README](../../../README.md#flash-sequence).

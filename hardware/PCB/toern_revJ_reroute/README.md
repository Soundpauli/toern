# Toern revJ reroute

Open `toern_revJ_reroute.kicad_pro` with Backplane KiCad 10.99.0-bp.12.5. This is the archived partial reroute, with 22 nets changed. Its board format requires the newer editor. The original `../toern_revJ` is the stock KiCad 9.0.5 version restored from commit `ab3ea41`.

The [validation summary](review/reroute/validation-summary.md) records results and remaining USB and thermal work. The [pre-restore checkpoint](review/reroute/baseline) preserves the active revJ files from before the restore. The [Specctra session and KiCad 9 seed files](review/reroute/ki9) are an unverified transfer attempt.

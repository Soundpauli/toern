AUTO & AGEN

Turn a motif into written variations or an evolving live arrangement. This chapter explains the controls, chord rules, registers, rhythm, probabilities and timing behind generation.

Choose the right kind of generation

TŒRN runs a local musical rule system: it measures your notes, chooses related rhythmic and harmonic candidates, then varies them with seeded pseudo-random numbers. The source pattern, voice roles and current section guide the result. It needs no network connection, account or downloaded model.

Which source page feeds each new page?

Let a be the source start, b its end, N the requested additional pages, and P = 256 / page width the available pages. AUTO writes from b + 1 through min(P, b + N). At zero-based destination offset j, it uses source page a + (j mod (b − a + 1)).

For example, source pages 1–2 plus four additional pages write pages 3–6, using source pages 1, 2, 1, 2. The engine changes the interpretation rather than simply duplicating each source. It cycles through subtle groove variation, response, lift/development and turnaround; a multi-page continuation ends with a turnaround. At the end of the 256-step pattern the requested output is shortened. If no page remains after the source range, nothing is written.

AUTO analyses the selected range, follows its voices and harmonic context, and evolves each destination from a source page. When a voice appears elsewhere in the source range, it can be brought into a response or development page. With PMOD active, the source page's mute map is copied to its continuation. AUTO's harmonic choices and page-writing arc are separate from AGEN's live section cycle.

AGEN — develop a live arrangement

  1. Select the edit page containing your motif. Choose a kit and set comfortable voice levels.
  2. Open MODE → AGEN and short-press encoder 4. The value changes to ON. Playback starts if it was paused.
  3. Return to the grid with touch 2. Listen across several sections; a new page is an answer to the motif, not a new random song.
  4. Use mutes, faders and CTRL volume during the performance. Filters, instruments and envelopes remain available for manual sound changes.
  5. Short-press encoder 4 on AGEN again, or pause, to end the temporary arrangement and restore the source notes.

The original note bank stays aside while two working pages alternate. An invisible workspace copy of the starting motif supplies each variation, so pitch shifts and deletions do not accumulate from one mutation into the next. Key and source register analysis are anchored to that starting material. On an empty page the firmware can create a restrained starter ensemble.

The amber centre rotates gently while AGEN prepares the next page; a steady green check means that page is ready and waiting for its boundary. It follows musical playback rather than estimating CPU time; there is no blinking number.

The section cycle and the drop

Groove → Variation → Groove → Break → Build → Drop → Variation → Groove, then repeat. Each section uses a related call/answer pair. Groove and Variation change density, phrasing and melody; Break removes supporting parts; Build raises tension; Drop restores the full user-level groove.

Build has one pass per page and leads directly to Drop. It does not repeat the roll a second time or insert a separate four-bar Fill section. CH2 provides the accelerating roll; CH3 keeps a steady supporting pattern. The final percussion sixteenth leaves a short breath before the next downbeat. Manual touch fills are an independent feature and retain their own two-page timing.

The time calculation

The grid uses sixteenths: step seconds = 60 / (4 × BPM). A page with W steps lasts 15W / BPM seconds, or W / 16 bars in 4/4. A complete buildup pair lasts 30W / BPM seconds.

For the other sections, the engine first chooses a bar budget: Groove and Variation normally use four or eight bars; Break and Drop use four. Page passes are max(1, floor(bars × 16 / (2W))). Long choices halve at slow tempos to aim for a 16-second cap, or 24 seconds for Break. The minimum is still one pass per page, so an especially slow two-page pair can exceed the cap. Build bypasses that budget calculation and always uses one pass on each page.

How the engine finds a key

A pitch class is a note name without its octave: pc = MIDI note mod 12, with C = 0, C♯ = 1, …, B = 11. The analyser collects weighted pitch-class evidence from bass, keys and pad roles. Bass notes receive extra weight, stronger notes matter more, and local/downbeat evidence helps establish an anchor. This gives a useful tonal estimate, not a promise to identify every ambiguous progression correctly.

It tests all twelve roots in major and natural minor. Their semitone intervals are [0, 2, 4, 5, 7, 9, 11] and [0, 2, 3, 5, 7, 8, 10]. For each candidate, the seven scale degrees receive weights [6, 2, 4, 3, 5, 3, 2]; notes outside the scale receive −4. The score is the sum of pitch evidence times those weights, plus bonuses of four times the first rhythmic group's root-bass evidence and twice its root-pitch evidence. The highest score wins.

AUTO can also score candidate triads against the source's local harmonic groups: root evidence × 5, third × 3, fifth × 3, seventh × 1 and root-bass evidence × 6, with a small preference for the proposed progression. This lets source notes outweigh a stock progression. AGEN fixes the inferred root and mode for its performance and uses its own section progression. With no tonal evidence, AGEN uses C natural minor as its harmonic starting point; percussion does not supply a reliable sung key.

The section cycle deliberately holds its transition harmony through Break and Build, then resolves to the tonic at Drop. Elsewhere, a change of chord, inversion, rhythm or contour can make the same starting motif feel different without abandoning its key.

CH11 chords: three voices that belong together

A diatonic triad takes scale degrees d, d + 2, d + 4, wrapping through the seven-note scale. In C major, starting at degree 0 gives C–E–G; starting at degree 3 gives F–A–C. These are scale-degree steps, not a fixed chromatic transpose of the original chord.

CH11 has up to three simultaneous notes. AGEN revoices existing multi-note onsets as a chord, including onsets between the fixed eight-step chord points. It also introduces chord attacks at regular eight-step points, with extra response attacks in Variation. A low multi-note CH11 source is still treated as harmony; a low monophonic CH11 source remains a bass line. Where the voice budget permits and both monos are available, CH13/14 can provide a third and fifth above a CH11 bass.

The inversion index is (generation + seed) mod 3. Root position, first inversion and second inversion reorder the same three pitch classes, raising wrapped tones by an octave. The whole voicing then shifts by octaves to put its average near the chosen register. The resulting pitches are ordered, distinct, no more than an octave apart and bounded within MIDI 24–108. Thus C–E–G can become E–G–C or G–C–E without turning into three unrelated random notes.

Changing inversion does not guarantee the smallest possible movement for every individual voice. It keeps a controlled, compact register and related answers. Sample voices 1–8 and mono synths 13/14 each remain monophonic; a grid collision is placed in a free row when one is available rather than overwriting another part.

Why generated notes do not need a huge CENT adjustment

AGEN chooses a musical register before applying the instrument's patch. CH11/13 melodic and harmonic references are kept around MIDI 55–79; bass references use MIDI 36–55. Individual melodic moves can travel up to an octave from their reference. Chord voicings have their separate 24–108 bounds. These reference ranges are not hard limits on every note played.

AGEN then compensates the patch's whole-octave register exactly once: stored generated pitch = desired pitch − patch octave shift. For CH11, the register shift is 12 × (register − 4). For CH13/14, the raw CENT slider maps to 1.5 × value − 24 semitones; the nearest whole-octave part is compensated. Raw slider values are internal units, not necessarily the signed label on the display. The mono grid-to-MIDI reference also includes the note table's MIDI-12 octave offset.

For example, a patch shifted down 24 semitones needs stored MIDI 84 to make a desired MIDI 60 sound at that register: 84 − 24 = 60. Fine tuning, oscillator-2 octave/detune and instrument character remain under your control. AGEN does not turn CENT, OCTV, INST or ADSR for you. Very low source chords can therefore become useful generated chords without editing the saved patch.

Rhythm, melody and probability

The companion engine follows voice roles: kick, snare, hat, clap and tom provide different rhythmic jobs; sample bass, keys/pad and synth parts use different note choices. It preserves structural anchors and develops offbeats, responses and turnarounds. Sparse Euclidean rhythm candidates distribute a chosen number of pulses through sixteen positions; rotations and related second halves produce alternatives. For phase t, rotation r and pulse count k, let u = (t − r) mod 16 with a nonnegative remainder. The candidate has a hit when k > 0 and (u × k) mod 16 < k. For example, four pulses at rotation zero give steps 1, 5, 9 and 13. The seeds decide among those candidates, so repeating an action can give a fresh interpretation.

AGEN's melody contour uses semitone suggestions [2, 4, 3, 7, 5, −2, 4, −5], reversed for the answer page and reduced for bass. A proposed move is fitted back to the chord on strong beats or the scale on passing steps. Bass quarter-note landings use the chord root. The chance of proposing a contour move depends on the role and section: bass 50%; other melodies 40% in Groove, 90% in Variation, 80% in Build, 65% in Break and 45% in Drop. These are proposal chances, not percentages of notes guaranteed to sound different.

In the buildup, progress runs across both pages. CH2 spacing tightens from every four steps to every two, then every step in the last quarter of the pair. Its nominal velocity rises from about 58 toward 114. CH3 supplies a steady offbeat. The last percussion step is cleared. Drop restores the quarter-note kick/backbeat structure and the user-level mix; it does not make every note a velocity-127 hit.

Playback probability is a separate decision. Structural kick, backbeat and tonal anchors are offered 100%; remaining hats/toms use generated ceilings of 60–95%, snare/clap 70–95%, and other voices 80–95%. The final probability is min(source probability, generated ceiling). A source note deliberately set to a lower probability keeps that limit. A pseudo-random hash of seed, channel and step supplies repeatable choices within a variation.

Manual touch 4 + 5 fills start on the next page, run for two pages and produce a velocity-127 final hit on the following downbeat. Several voices can be queued independently. AGEN does not automatically stack this second fill engine over its generated buildup. See Performance fills for the gesture and re-arming rules.

Volume, backing parts and your manual controls

Before building a transition, AGEN looks for a source backing part that is present, unmuted and has a nonzero starting voice level. It prefers sample bass, CH14, CH11, CH13, sample keys/pad, then kick. If no such foundation exists, Break/Build/Fill requests fall back to Groove. A hats-only source therefore does not manufacture a percussion buildup while all backing voices are muted.

The chosen backing part is retained through transitions at a scale of at least 12 / 16 of its starting level, subject to integer rounding and manual controls. Other parts thin or rise according to their roles. For base voice level V and section scale s, the target is floor(V × s / 16). A base level of 12 with scale 12 becomes 9. For the CH2 buildup, s = 5 + floor(11 × progress / 255), so a base level of 12 rises from 3 to 12.

Automation updates at roughly 30 ms intervals and moves one voice-level unit toward its target per update. Drop restores the target immediately on entering the section. Moves stay at or below your chosen ceiling. Turning the physical CTRL=VOL encoder sets a new ceiling for that voice and gives the manual value priority for two seconds. Fader gain and its mute zone still apply; a full-velocity note cannot override a silent fader.

AGEN's automatic sound-control changes are volume changes. Filter cutoff, resonance, reverb, attack and other patch settings remain manual. You can shape the sound without the generator repeatedly undoing your choices.

Original notes, saving and stopping

AUTO writes ordinary pages in the current pattern. AGEN allocates a temporary workspace only while active: the original bank stays available, two pages perform, and an additional hidden anchor supplies fresh variations. It prepares at most one voice per main-loop pass. The sequencer publishes a page only when every voice has finished; generation and SD file work do not run in the timing interrupt.

Turning AGEN off or pausing restores the original note bank, selected page, starting mute state and automated voice levels. Manual filter/instrument changes remain live. Opening PATT, NEW, SONG or TOUCHY, changing display width, starting recording or switching a file subpattern ends AGEN. Pattern save/load restores the original bank first. Temporary variations are not autosaved, and AGEN is not remembered as enabled across a reboot.

If CHLD, IMG, TOUCHY, recording or a pending pattern-bank operation makes the temporary workspace unavailable, AGEN refuses to start. Allocation failure also leaves the existing note bank and transport intact. To keep generated pages as a composition, use AUTO and save the resulting pattern; to keep the sound of an AGEN performance, capture USB audio on a computer or use an external recorder. Starting the on-device recorder ends AGEN.

A practical first session

  1. Make a one-page groove with kick, a bass or harmonic voice, and a few hats. Put a simple CH11 chord on beat 1 if you want to hear voicing changes.
  2. Set voice levels and save the motif. Try AGEN for a full section cycle before judging its variation.
  3. Listen for the call/answer changes, retained backing part, accelerating CH2 roll and direct next-downbeat drop.
  4. Turn AGEN off. Your motif returns. Use AUTO to write a few variations after it, then edit the result and save a second pattern.

When something sounds unexpected

Too little variation: use more than one melodic onset or a real multi-note CH11 chord, and listen through Variation as well as Groove. Sparse or low monophonic CH11 input can be treated as bass; it will not suddenly become a three-note pad. Very low or quiet: check patch tuning, voice ceiling, fader position, note probability and sample tuning. AGEN register compensation is for its generated synth notes, not a global retuning of your existing pattern. A late change: inspect the red/yellow next-page dot; an unfinished page repeats safely. Nothing to keep: AGEN restores its source by design; AUTO writes editable pages.

SD card

The card that comes with TŒRN is ready to use. This chapter explains how to change its contents and restore the defaults.

Changing SD card contents

The SD card that comes with TŒRN is already prepared. To change its contents, use the SD tool while the card stays in the unit, or connect it to a computer with a card reader.

SD tool (card stays in the unit)

On a computer, open https://sdtool.tyng.app in Chrome or Edge, click Connect, and pick the Teensy serial port. The card server answers from any screen. Menu → ETC → SD shows SCON, then WAIT in yellow until a host is talking and OK in green after that. Browse folders, upload WAVs (the site converts to 44.1 kHz mono 16-bit), download, rename, or delete. You can drop multiple files, whole folders (subfolders kept), or a .zip (extracted in the browser into the current SD folder).

Tips: leave the unit on whatever screen you are playing. Opening the serial port can reboot the Teensy; connect again after it comes back. Desktop only: Android / Pixel Chrome usually cannot see the Teensy USB serial port. After big transfers, run ETC → RSET → SD if the sample browser still looks stale.

Restore the default contents

If you need to restore the card, the default folder layout, sample kits, and starter settings are available from the TŒRN Sample converter (audioconvert.tyng.app). Open the SD CARD section and download SD-CARD-CONTENT.zip. Extract the ZIP and copy all files and folders to the root of your microSD card (not inside a subfolder). Full instructions are on that page.

If the sample browser does not reflect new card content after power-up or after using the SD tool, run ETC → RSET → SD to rescan.

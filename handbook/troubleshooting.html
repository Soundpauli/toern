Troubleshooting

Quick fixes for the surprises new owners hit most often, plus a careful walkthrough of the destructive reset ladder.

After flashing firmware

Power-cycle the device after flashing before testing audio, touch controls or the SD tool. On external-touch hardware, use a firmware build configured for that panel. After restart, reconnect the SD tool if needed.

"I expected X but got Y"

The matrix is half-dark — only the top or bottom half lights up.

You have one LED board, but the firmware is set to two-board geometry (or vice-versa). Open ETC → ADV → LEDS and try 1, 1B, 2, 2B in turn — one will match your hardware. The "B" variants flip the image for boards mounted upside down.

No sound on headphones.

Check three places in order: VOL → MAIN (level above 0), VOL → GAIN (1.0x is the old mix staging; 0.0x mutes a bus), VOL → SPKR (sometimes the speaker is overriding routing), and the headphone jack is fully seated. If line-out works but phones don't, you have a hardware fault — open the unit to inspect the TRS jack.

Samples don't show up in the browser.

The firmware caches the browse list. Run ETC → RSET → SD: it rescans the card without touching your patterns. If they still don't appear, confirm the files are 16-bit mono WAV at 44.1 kHz and that the card was prepared with the layout from the SD card chapter.

SD tool cannot connect / no serial port.

Use desktop Chrome or Edge at sdtool.toern.live — Android / Pixel usually cannot see the Teensy USB serial port. The card server answers from any screen. ETC → SD shows SCON: WAIT in yellow, then OK in green while a host is talking. Opening the port can reboot the Teensy; connect again after it comes back. See SD card → SD tool.

External MIDI is in sync but kicks click off by a few ms.

Use MIDI → SYNC. SYC> delays TOERN’s playback when it sends Play; SYC< delays its playback when it receives Play. Negative values add delay to the opposite path. Adjust in 1 ms steps and restart to hear the correction. A red -- means the selected value has no effect in the current mode. Settings persist.

BPM number is red and won't settle.

You are on EXT clock and the incoming MIDI clock is unstable or absent. Either fix the master (cable, source clock setting) or flip BPM → encoder 3 back to INT to use TŒRN's own clock.

I switched kits and now my pattern sounds wrong.

Kits change what each voice row plays. The pattern still references the same rows, but they now contain different samples. Either reload the previous KIT (encoder 1 short on the KIT screen with the right number), or — for next time — save a PATT pattern per KIT and record the matching KIT number alongside it.

I cleared the wrong page.

There is no undo in RAM. If you previously saved to PATT, reload that slot. Otherwise, it's gone. The handbook's golden rule: save to PATT when an idea matters.

Battery percentage seems to lie.

The reading is a fuel-gauge estimate from the charger IC. It is good faith but not lab-grade. Charge for at least one full cycle (USB until full, run until shutdown) before trusting the curve.

Touch pads trigger by themselves.

Capacitive pads detect skin contact. If your palms rest on the chassis while turning encoders, you may register phantom touches. Lift your grip; if it persists in dry conditions, a power cycle re-calibrates the pad baseline.

Encoder feels jumpy — values fly when I turn slowly.

The hardware encoders are I²C and can occasionally desync. Power-cycle the unit; on rare occasions, also re-seat the SD card. Persistent issues are a hardware fault.

Long-press encoder 4 on a note doesn't open the editor.

You are in paint mode (SETT → DRAW = L+R) and encoder 4 long is reserved differently. Switch DRAW to the default or use a single tap on encoder 1 to enter single mode first.

I see a moving dot when I'm not playing — what is it?

If you see a bright dot with a short trail bouncing around your pattern in draw mode while MODE → PONG is ON, that is PONG: the ball only hits and fires notes on muted voices (unmuted play stays clean). Turn PONG off from the same menu page, or open it to change speed (encoder 2, 1–99). If you see a pair of cartoon eyes after long inactivity when not playing, that is the separate idle matrix animation, not PONG.

Sample browser won't open — the touch combo seems to do nothing.

The sample browser only opens on sample voices 1–8, with the left pad pressed first. If your cursor is on a synth row, the combo opens the filter editor instead. Move encoder 1 to a sample row and retry.

Note-shift exited without saving my moves.

Note-shift saves continuously — once you exit with a short press on encoder 4, the new positions are committed. If a particular nudge looked unsaved, you may have moved a note off the visible page range; check adjacent pages.

Auto-preview is too loud.

Drop VOL → PREV, or switch VOL → PREV from ON to PRSS (press encoder 1 to audition) or SYNC (hear the file on the voice's pattern hits).

The reset ladder (ETC → RSET)

Seven rungs live behind one encoder dial. Encoder 3 rotates the mode; encoder 2 confirms. Read each row before confirming.

Power-on hold (touch 1)

Hold touch 1 while switching on. Let go before 3 seconds and the boot continues. At 3 seconds the matrix shows FULL / OK: the boot then runs ETC → RSET → FULL, including the sample-card scan, and keeps the LED panel setting. Keep holding and a RAM countdown runs. At 10 seconds every EEPROM byte is cleared and the matrix shows RAM / OK; FULL still runs, so the panel layout returns to one panel. Let go during that countdown and the wipe is skipped. FULL still runs.

There is no undo beyond reloading saved pattern files. If you choose FULL with unsaved work in RAM, that work is gone.

Last-resort recovery

  1. Soft restart — slide the power switch off, wait five seconds, slide on. Most freezes resolve here.
  2. SD re-seat — power off, push to eject, reinsert firmly, power on. Fixes most "samples missing" cases that SD rescan didn't.
  3. Re-flash the firmware — over USB C, using the Teensy 4.1 boot procedure. Pattern files on the card are not affected by a firmware reflash unless you also reformat the card.
  4. If touch pads stay stuck — make sure the chassis is clean and dry; cap-touch baselines re-calibrate on boot.

For deeper hardware issues (encoder gone, LED out, jack scratchy), inspect the unit; the schematic and KiCad sources are in PCB/toern_revG/.

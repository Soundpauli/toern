Song mode

Turning loops into a set list: how the 16 pattern pages relate, what PMODE does, and how the SONG arranger chains pages together.

Pattern pages, loops, and PMODE

One pattern holds 256 steps: 16 pages × 16 steps on a single panel, or 8 pages × 32 steps on a wide panel. The page strip on row 16 (see Matrix) shows which pages have content. How playback walks pages is set by SETTINGS → PMD (PMODE):

ModeWhat playback doesBest for
OFFAdvances through the pattern pagesA→B→C sequences
ONLoops the selected edit pageLocked loops and live tweaking
SONGFollows the SONG arrangerNon-linear set lists, repeats, bridges.
NEXTWaits for a cued target then jumps onceLive transitions on a queue.

The SETTINGS → LOOP setting caps how many steps in a page actually sound (or OFF for the natural 16). Short loops feel groovebox-like; longer loops feel more linear.

The SONG arranger

Open SONG from the root menu. The screen shows a chain of up to 64 slots, each pointing at one of the pattern's 16 pages. With PMODE = SONG, playback steps through the chain and wraps back to the start.

Example: page 07 written into song slot 23.

1 Encoder 1
ShortClear assignmentClears the selected slot; later slots stay in place.
2 Encoder 2
TurnPattern page (1–16)Picks which page goes into the currently selected song slot. The page number is shown in that page's voice colour.
ShortAssign pageWrites the selected page to this slot.
3 Encoder 3
ShortTransport (play/pause)Starts the chain in SONG mode. Stopping also sets PMD to OFF.
4 Encoder 4
TurnSong slot (1–64)Moves the edit cursor along the chain. The currently sounding slot is shown as a bright dot moving along row 1 while playback runs.
ShortAssign pageSame as encoder 2: writes the selected page to this slot.

Workflow: set PMODE to SONG, open the SONG screen, choose a slot with encoder 4, dial the pattern page with encoder 2, press encoder 2 or 4 to assign it, then repeat. Empty slots are skipped. During playback you see two strips at once: the page strip on row 16 (which pattern page is currently sounding) and a moving green dot on row 1 (which song slot you are on).

Tip: chains can repeat. Put the same page in three consecutive slots to "stay" on it for three loops before moving on, or alternate page 01 / page 02 / page 01 / page 02 to create a call-and-response.

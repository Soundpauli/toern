The matrix

TŒRN has no screen besides the RGB LED grid — the same surface you tap notes onto is also the display. This chapter teaches you to read every row, lane, and helper before you place a single note.

Time goes sideways, voices stack upward

The grid is a two-dimensional score. The X axis (columns 1…32) is musical time: column 1 sounds first, column 32 last. The Y axis (rows 1…16) is voices stacked from bottom to top — row 2 is voice 1, row 3 is voice 2, and so on. Two rows are reserved as helper strips: row 1 at the very bottom and row 16 at the very top.

Read direction: firmware numbers pixels with (x, y) using 1-based coordinates and y=1 at the bottom. Wherever this handbook says "row 1" it means the lowest visible row of LEDs, and "row 16" the highest.

Anatomy: tinted voice bands fill rows 2–15; row 1 (bottom) is the 4/4 beat guide; row 16 (top) is the page strip.

Row 1 — beat guide

In default Draw mode the lowest row is not a voice lane. It shows a quiet 4/4 orientation bar: dim markers every fourth step, starting at step 1, across the full grid width so you can spot beat one and each downbeat while you edit. No notes can be placed here — painting starts on row 2.

With the cursor on row 16, row 1 instead paints encoder-hint glyphs so you know which knob is armed for page-wide tools — see Pages+More.

Row 16 — TOOL-LANE

The top row combines the page strip (one LED per pattern page; up to 8 pages) with the TOOL-LANE, where page-wide actions are available when the cursor is on row 16.

TOOL-LANE actions (cursor on row 16):
  • Delete a page by unpainting its strip LED
  • Copy & paste a page
  • Clear the current edit page (single mode)
  • Random / scale-aware fill for the focused voice (single mode)
  • Note-shift — moving a whole voice's notes in time / across rows (single mode)
The hint strip on row 1 shows which tools are active. Step onto a voice row to return to per-note editing.

Rows 2–15 — the voice lanes

Rows 2–15 show voice lanes. Voices 1–8 are samples, 11 is the three-voice poly synth, and 13–14 are mono synths. Voices 9, 10 and 12 are unassigned; the hint and page strips are navigation, not additional sound voices. In DRAW, a voice appears one row above its channel number; in SINGLE, rows represent pitches of the selected voice.

Voices 9, 10, and 12 are intentionally empty — no sound engine is wired to those rows; you may still move the cursor there, but notes placed on them do nothing. The cursor & the playhead

The grid shows an edit cursor and a playhead during playback:

  • The edit cursor is your working tool: it marks where the next gesture will land. Encoder 4 moves it across columns; encoder 1 moves it between rows. A row-number helper can be shown beside it to make its position easier to read.
  • The playhead is a red vertical line that runs left to right across the visible page — the column the sequencer is currently sounding. Notes under it light brighter as they fire; muted lanes stay dark.

When playback is stopped, only the cursor moves. When playback is running, the red playhead marches across the page while the cursor stays wherever you left it.

What a "mode" actually means

The matrix swaps role between modes. The two core sequencing views are explained in Sequencing:

  • Draw — full LED grid view, every voice visible at full intensity.
  • Single — focus on one voice at a time, other voices dimmed.

In other modes, the matrix shows controls or information for that task. Menu mode overlays text and submenu dots; playback can continue while you navigate. The Menu map covers every screen.

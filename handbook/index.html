TŒRN is a sampler and step sequencer. The RGB LED grid is the display: time runs left-to-right across each row, voice lanes stack upward, and four rotary encoders on the edge let you draw, sculpt and arrange. Samples live on a Micro SD card; a built-in three-voice synth and two mono synths cover melodic work; eight sample lanes carry drums and one-shots; everything can be recorded right from the device.

This handbook is the path after your TŒRN arrives. If you like, use the simulator beforehand to get to know the device. Start with Your first beat in 1 minute, then read onward — each chapter builds on the one before. Power is USB-C. Card setup is in the SD card chapter. Power users can jump to the screen index or the menu map.

How this handbook is organised

Three groups in the sidebar follow the same arc a new owner walks through:

  • Get started — a one-minute first beat, then anatomy of the device (hardware, matrix layout, control surface). Read these first.
  • Compose — actually making music: sequencing, pages, advanced tools, samples, sound design, the audio path, recording, and per-step note detail.
  • Operate — running the box as an instrument or studio member: tempo and MIDI, song mode and saving, the full menu, plus a flat screen index and troubleshooting.

Every chapter shows the matrix display where it applies. Encoder behaviour is given in four-column tables (one card per knob); destructive or sneaky gestures get a callout. Cross-links point to the menu map and screen index whenever a feature has a menu page of its own.

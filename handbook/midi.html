TRAN — transport

Start / stop / continue messages.

OptionEffect
OFFIgnore and never send transport.
GETListen for MIDI start/stop so an external sequencer can run TŒRN.

GET pairs with EXT clock; SEND pairs with INT clock.

SEND — what leaves the MIDI out

OptionEffect
CLCKClock pulses only — simplest sync-out.
NOTENotes only — drive an external tone module.
BOTHClock + notes.
No separate OFF on this page — mute notes via RCVE, or stop being clock master via BPM → EXT.

RCVE — incoming notes

OptionEffect
NOTEIncoming notes trigger internal voices per CH.
OFFIgnore notes — pure sequencer / recorder.

CLMP — incoming pitch range

OptionEffect
ONFold incoming YPOS/MIDI notes by octaves into rows 1–15; preview and playback use the visible row pitch.
OFFKeep the original MIDI pitch for preview, recording, playback, and MIDI out. The note is still folded into a visible editable row; moving it vertically transposes the stored pitch.

CLMP does not alter the legacy KEYS trigger mapping. The setting defaults to ON and survives reboot.

PPQN — analog clock pulse

Analog clock on the dedicated 2-pin headers — independent of TRS MIDI. CLK-OUT (J25) is 5 V. CLK-IN (J26) is 3–5 V: on the BPM screen, click encoder 3 for an orange < (analog in) instead of the red < (MIDI in). Pulse width 1–50 ms (default 12).

1 Encoder 1
TurnPulse width 1–50 msWhite LED. Default 12 ms.
2 Encoder 2
TurnSTOP / CONTSTOP = pulse only while playing. CONT = always (legacy).
3 Encoder 3
TurnOFF, then 1 / 2 / 4 / 8 / 12 / 16 / 24 / 32Pulses per quarter note.
ClickPolarity + / −Green + = active high. Red − = active low.
4 Encoder 4

Rate 1 = one pulse per beat; 24 ≈ classic Sync24 density; 32 denser than MIDI’s native 24 PPQN. Display follows the last encoder you turned: width, STOP/CONT, or ±rate. This page is output on J25. Incoming analog rate is CIN.

Jacks (rev H silk): CLK-OUT(5V) = J25, CLK-IN(3–5V) = J26, SIDEC-5V = J27 (see SIDE). Pin 1 = signal, pin 2 = GND. Incoming analog clock is read on CIN, not here. Not MIDI DIN and not line-level audio.

CIN — analog clock in

Config for CLK-IN (J26). With orange < EXT on the BPM screen, incoming pulses advance the sequencer. At 4 PPQN each pulse is one step, at 24 PPQN every sixth pulse is.

1 Encoder 1
TurnWID 1–32Hold-off in ms: rises sooner than this after a counted pulse are ignored. Keep it below the pulse spacing.
2 Encoder 2
3 Encoder 3
TurnPPQN 1 / 2 / 4 / 8 / 12 / 16 / 24 / 32Pulses per quarter note of the incoming clock. Default 4 (one pulse per 16th, Volca).
4 Encoder 4

Display follows the last encoder you turned. The pin-38 interrupt is armed only in orange EXT; INT and MIDI-EXT ignore CLK-IN. Press Play and the sequence starts on the next pulse. At 1 and 2 PPQN a pulse covers 4 or 2 steps: the first plays on the pulse, the rest are spaced by the last pulse interval.

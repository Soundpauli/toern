Sound design

Voices have different signal paths. Samples and synths have envelopes, filtering, delay and effects, with reverb available only on selected voices. This chapter walks each stage and the voice-specific filter pages where you control them.

New notes, default auditions and initial TOUCHY hits use velocity 127. Existing patterns and incoming MIDI keep their own velocities. Resetting all sound pages shows a blue checkmark for 800 ms, then returns to the filter page.

The signal chain

A sample voice broadly follows this path. Reverb is available on voices 1, 2 and 5–8 and the poly synth; voices 3, 4, 13 and 14 do not have a reverb send.

Source → ADSR envelope → Bitcrusher → Multimode filter → Reverb (selected voices) → Pan / Gain → Output

The chain above is the musical idea. The actual Teensy graph (every mixer gain, amp, and bus) is on Audio path — including that bitcrush sits before the SVF, not after.

PSET — synth voice presets

On voices 11, 13 and 14, the main menu’s SMP item becomes PSET. Encoder 4 selects slot 1–99; encoder 1 loads, encoder 2 saves, and encoder 4 short press exits. Each synth has its own slots. Occupied slots appear green; empty slots appear blue. Success shows a green check; failure shows a red cross.

A preset stores that synth’s filter, synth and envelope parameters. It does not replace the pattern grid or sample kit. On hardware the files live in presets/11/001.pset, presets/13/001.pset or presets/14/001.pset. Simulator presets are stored separately in the browser.

The filter pages

Enter from the grid with the both-touch gesture, right pad first. (Left-first on sample voices opens the sample browser instead.) Each filter page is a vertical mixer strip split into four encoder columns. Turn an encoder to edit; short-press to assign that parameter as the fast-filter default (encoder 3 from draw mode will recall it). Encoder 3 long press is play/pause so you can audition without leaving the editor. Pages cycle with a tap on touch 2.

How each filter page is drawn: at rest the matrix shows four narrow vertical sliders with a single letter printed next to each one — that is all the space the grid has. The moment you start turning an encoder, the device replaces those tiny letters with the parameter's full 4-letter name spelled out across the lower rows, in the colour of the parameter you are changing. Release the encoder and it falls back to the resting letters.

Page 3 — sample voices: DLAY · VOLUME

Voices 1–8 have a fourth filter page with DLAY and VOLUME sliders. Real delay tap (AudioEffectDelayExternal in PSRAM), not reverb. 0 is off; each step is N/32 of a beat (1, 2, 4, 8, 16, 32 land on even divisions; 3, 5, 6… stay in between). 32 is one beat, not a fixed 1.2 s. Follows BPM. Feedback recirculates the tap; dry stays up. Synth voices 11, 13, and 14 have the same control on CRF (encoder 4).

V — VOLUME is available only on sample voices 1–8, beside D on encoder 2. Its center value 0 is normal gain (1×); −16 is fully silent (0×), and +16 doubles gain (2×). It scales that voice’s complete effects output independently of fader velocity and channel volume. Resetting this page returns V to 0. The setting is saved with the pattern; older patterns open at neutral gain.

Page 3 — ADSR: ATCK · DECY · SUST · RELS

At rest

Letters A · D · S · R — attack, decay, sustain, release.

Encoder turning

Full name SUST while encoder 3 is being moved.

Attack — time from trigger to peak. Decay — time from peak to the sustain plateau. Sustain — held level while the note remains on. Release — fall after note-off. Each parameter is 0–32 on the encoder; the firmware maps it to milliseconds (A / D / R) or 0–1.0 (S).

Tip: tweak release last. Long release smears notes into the next step; pair short release with high sustain for staccato drums.

ADSR in detail

All voices share the same envelope generator. Channel 11 (poly synth) additionally has a filter envelope with its own A/D/S/R that modulates the filter cutoff — same encoder layout, different page nest. Reach it through filter page 1 on voice 11 (the third filter row swaps in for filter-ADSR when applicable).

  • Attack 0 = instant click. Use for percussive material.
  • Decay 0 + Sustain max = organ-style hold. Use for pads.
  • Release 0 = note shuts immediately at the next step. Use to tighten busy grooves.

The reverb is a global shared bus. Only voices with an active RVRB control can send into it (see filter page 0 above). Balance wet against dry by mixing send amounts on the lanes that support it.

Fast filter (encoder 3 from the grid)

From draw or single mode, turning encoder 3 twists the parameter chosen as the fast-filter default for the current channel. That choice is set in the filter editor: short-press a column to mark it as that voice's macro. The next time you spin encoder 3 from the grid, you are sweeping that control.

The same encoder 3 fast filter stays available while you hold encoder 2 for the mute / solo overlay (green ring). Random sample pick moves to encoder 4 for that hold.

Most players assign HCUT as the default for sample lanes and CUT for synth lanes. Lanes can each have their own choice — the firmware remembers per channel.

The synth voices in detail

Voice 11 — 3-voice polyphonic synth

Three oscillators per voice, three voices of polyphony, thirteen instrument presets in a single ROM-style table (BASS · KEYS · CHPT · PAD · WOW · ORG · FLT · LEAD · ARP · BRSS · 303 · DXEP · DXBS). Each preset bundles a waveshape recipe, envelope curve, and filter envelope amount. The default instrument is DXBS. 303 provides acid bass, DXEP a bell-like electric piano, and DXBS an FM-style bass. Independent ADSR per voice, independent filter envelope per voice, per-voice pan, gain, waveform, fine pitch (cents), and coarse pitch (semitones).

Selecting an instrument loads its matching filter, register, waveform, and ADSR defaults. The presets deliberately cover different roles: PAD and WOW swell, ORG uses clean drawbar-style harmonics, FLT is breathy, LEAD is a square-forward pluck, ARP is a tight pulse stack, and BRSS uses a darker saw body with a slower filter bloom. You can edit the loaded values immediately; saved projects retain those edits.

A fifth filter page matches voices 13/14: LFO R · LFO D · SPAN · ARP. The LFO runs on the shared SVF and the poly ladders (cutoff + resonance). ARP is MIDI-hold only and does not transpose notes already on the grid.

Voices 13 & 14 — 2-oscillator mono synths

Two oscillators each, full ADSR. Filter page 0 swaps RVRB for CENT (coarse pitch) in the third column — there is no reverb send on these lanes. They add two performance modulators:

  • LFO — rate 0.25–10 Hz (0 = off), depth 0–100%. Sweep is wide (±6 octaves at full depth) on cutoff and resonance. Independent of SPAN/ARP.
  • Arpeggiator — MIDI hold only. Encoder centre (16) is off. Above centre: 16th-note arp; below centre: 8th-note arp. Amount is the distance from centre (interval). Grid notes play as written. In SINGLE while playing, each arp hit is recorded at its sounded pitch.

Waveforms include sine, sawtooth, square, and triangle. These channels are great for basslines and lead lines where polyphony is unnecessary.

Normal sequencer notes retrigger their envelope. To connect adjacent notes on voices 11, 13, or 14, mark the destination note G/L in note detail: repeating the same pitch holds the existing envelope, while a different pitch retunes the active voice without restarting it. G/L without an adjacent source attacks normally; a gap ends the phrase. No separate R/T setting is needed because every non-G/L note already retriggers.

Voices 9, 10, 12 — empty rows

These matrix rows are reserved but intentionally carry no voice. The cursor can visit them, but placing notes or opening filters has no effect — there is no audio path. See The matrix → voice lanes.

Per-voice tuning

  • Global transpose — semitone offset added to the synth pitch path. Currently a code-level hook (initialised to 0); no menu page exposes it.
  • Channel detune — −12 to +12 semitones, per channel.
  • Channel octave — −3 to +3 octaves, per channel.
  • Synth-11 fine tune — −50 to +50 cents per voice.
  • Synth-11 semitone offset — −2 to +2 per voice.

These add together. Big-picture tuning lives in detune + octave; subtle character lives in cents + semitone offset.

Resetting a voice

From the filter editor of any channel, encoder 4 long press resets envelopes, filters, and synth data for that channel only. Note data in the grid stays intact — only the tone snaps back to factory curves. To reset the whole project's sound layer (every voice), use ETC → RSET → EFX; that one is destructive across the board.

EFX reset is global. Patterns and sample assignments survive, but every filter, envelope, synth, and octave helper goes to defaults across all 16 channels.

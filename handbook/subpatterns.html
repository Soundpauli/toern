Subpatterns

Five lettered slots A–E behind one PATT number. Turn them on in SETT → SUBP, then hold FN and turn encoder 2. Sounds stay put; only the notes change. This is not SONG chaining and not the mute overlay.

FN + encoder 2 — pick A–E

On the draw or single grid, with SUBP ON, hold touch 5 (FN) and turn encoder 2. The grid keeps rendering. A centered overlay shows the letter and page, like FILL: A1, B3, and so on.

While another letter is on screen, the playhead column is yellow instead of red — you are looking ahead; the current slot is still sounding.

Release FN to arm the chosen letter. Playback keeps the old slot until the same page boundary PMOD → NEXT uses, then swaps. Stopped playback installs it immediately. If the new slot has notes on the page you were looking at, that page stays; otherwise the first page that has notes opens. The X cursor stays in its column.

An empty letter becomes a blank grid with the current sounds. Picking the letter you are already on leaves the notes unchanged (it can still jump to a page you previewed). Recording, child lock and image mode do not open the selector. An unreadable target leaves the current grid in place.

No FN, no letters. The external button panel has no fifth pad, so SUBP selection is capacitive FN (touch 5) only. In the simulator, hold M and turn encoder 2.

When a switch is written

Switching letters while playing never writes the SD card. Pause, then switch, to save the slot you are leaving (including a newly created blank). A numbered pattern stays N.txt until a lettered slot is saved; the first paused switch promotes it to N-A.txt. After that the family is N-A.txt … N-E.txt.

PATT load and save talk to the letter you have selected. A manual empty PATT Save deletes that letter. Automatic paused-switch saves keep a blank grid as a real file. NEW and a load of a pattern that has no N-A.txt stay a single file — leftover B–E files from an old family are not reused.

ETC → RSET → PATT removes numbered patterns and their lettered companions.

Save keepers while paused. Live A–E flipping is for performance. If you need the outgoing slot on the card, stop first, then change letter.

What SUBP is not

  • It does not walk letters automatically. SONG still arranges pages of the current slot.
  • It is not the long-press encoder 2 mute / solo overlay on a voice row.
  • FN + encoder 2 long on the page row still writes a page. The letter selector is the turn while FN is held.

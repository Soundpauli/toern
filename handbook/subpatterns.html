Subpatterns

Keep up to five variations, A–E, under one PATT number. Each letter has its own complete note grid and pages. Switching letters keeps the current sounds and settings.

Prepare while stopped; perform while playing. Switching letters during playback does not save the edits you leave behind. Save each variation before using live switching.

1. Enable subpatterns

Open SETT → SUBP. Turn or press encoder 3 to choose ON. SUBP starts OFF; your choice survives reboot.

OFF: the FN letter selector is disabled.

ON: FN + encoder 2 selects a letter in DRAW.

2. Choose a letter; inspect its pages

In DRAW, hold touch 5 (FN) and turn encoder 2 to select A–E. The grid previews the selected letter while FN remains held. The selector stops at either end; it does not wrap.

While holding FN, turn encoder 3 to preview pages containing notes in that letter. Empty pages are skipped and the ends do not wrap. The overlay shows the letter and page: B3 means B, page 3.

Green means the slot has file data, or is already open in RAM; it does not guarantee that your latest edits are saved. Blue means no saved slot was opened; selecting it creates a blank grid. During playback, a yellow playhead tells you that another letter is being previewed while the current letter still plays.

The selector works in DRAW, outside recording, child lock and image mode. FN is the fifth capacitive pad; the external button panel has no equivalent. On the page row, a long press of encoder 2 still generates notes. Turn it to choose letters.

3. Release FN to switch

Release FN to request the selected letter. The transport determines when it opens:

TransportWhen the notes changeWhat is saved automatically
StoppedThe selected letter opens immediately.The outgoing letter is saved afterward. A newly created blank destination is also saved.
PlayingThe change waits for a playback boundary and for the target to finish loading.Nothing. Save edits before leaving their letter.

With PMOD, the current page finishes. With PMOD off, the complete pattern loop finishes. VMOD waits for its complete voice cycle. If loading misses a boundary, the change waits for a later one.

The previewed page opens if it contains notes. Otherwise the first page with notes opens; a blank letter starts on page 1. Playback starts at that page’s first step. The X cursor keeps its column. Choosing the current letter preserves its notes and can move to the page you previewed.

Letters exchange notes; the sound setup stays live. Samples, synth settings, tempo, effects, volumes, mutes and the SONG page arrangement remain unchanged. SONG sequences pages within the active letter; it does not select A–E.

4. Make an A/B pair

Start with a loaded numbered pattern in A and stop playback. To make B as a separate variation:

  1. Hold FN, turn encoder 2 to B and release FN. A is saved; if B does not exist, it opens blank.
  2. Write the notes for B.
  3. While stopped, switch back to A to save B. You can also save the active letter through PATT, using encoder 2 and confirming an overwrite if asked.
  4. Start playback. Select B with FN + encoder 2 and release FN; B enters at the appropriate playback boundary. Prepare C–E the same way.

5. Understand the pattern family

A is the original numbered file. Pattern 42 uses these names on the SD card:

LetterSD filename
A42.txt
B42-B.txt
C42-C.txt
D42-D.txt
E42-E.txt

B–E are companion files; adding them does not rename A. 42-A.txt is ignored and never used as a fallback. Each file stores a complete pattern, although FN switching reads its notes and keeps the current sound setup.

In PATT, a green folder and green dots describe the selected family to load. A counts as one dot; five is the maximum. A red folder and red dots mean the selected number is empty and preview the currently loaded family that Save As will copy there.

Saving to an empty number copies the saved siblings and the active letter’s latest RAM contents. After a successful Save As, the new number becomes the loaded family. Merely browsing another number does not change the family used by FN switching.

Saving over another occupied number opens SAVE? / NO. Confirming replaces that destination family, removing letters that exist only in the old destination. Saving to the current family updates the active letter and preserves its siblings.

6. Delete deliberately

Saving an empty grid never deletes its family. To delete a numbered family, select it in PATT, hold FN and press encoder 2 beneath the red X. This opens DEL? / NO for the selected number, including all its A–E files and recovery files.

For DEL? or SAVE?, turn encoder 4 to choose blue NO or green YES, then press encoder 4. Encoder 2 does not confirm. NO returns to PATT with the animated blue neutral face. Touch 2 also cancels. See the confirmation screens.

Deleting another family leaves the live notes alone. Deleting the loaded family clears them. ETC → RSET → PATT removes all numbered families.

7. Recovery and SD errors

Pausing also checkpoints the session to autosaved.txt, shown as AUTOSAVE in PATT. This is separate from numbered saves. It does not save every letter or recover unsaved edits from a letter you already left during playback.

If ERR appears during a paused save, the pending edits stay in RAM. You can resume the current letter, but further letter changes remain blocked. Resolve the SD-card problem and pause again; the save retries automatically while stopped. Automatic retries never write during playback.

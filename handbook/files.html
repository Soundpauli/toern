Files — load & save

PATT is the pattern slot screen — the place to save a numbered pattern. This chapter covers load/save, the NEW pattern generator (first PATT entry), stored settings, autosave, and how patterns relate to sample kits.

PATT — pattern slots

Open PATT from the root menu. The big number selects a load target. A green folder means that numbered family exists; its green dots count saved A–E files, including A. A red folder means the selected number is empty; red dots preview the loaded family that Save will copy there. There are at most five dots, beside the folder.

Green folder and dots: the selected load target has five saved subpatterns. A counts as one dot. The folder is compact on a 16-column matrix.

DEL? / SAVE? — choose before replacing files

FN + encoder 2 in PATT opens DEL? / NO for the selected numbered family. Save on an occupied selected number opens SAVE? / NO to overwrite it with the loaded family. The target number stays fixed while you choose.

Blue NO cancels; green YES confirms. Both screens start at blue NO. DEL?/SAVE? stays red; the choice text, encoder 4 ring and indicator are blue for NO and green for YES. Turn encoder 4 clockwise for YES, or counterclockwise for NO. Press encoder 4 to execute that choice. Only encoder 4 press executes the selected choice; encoder 2 does nothing on this screen. Touch 2 also cancels.

DEL? / NO is the initial choice. Press encoder 4 here to cancel without deleting files.

SAVE? / YES means overwrite the selected family when encoder 4 is pressed. Letters present only in the old destination are removed.

Cancel returns to the originating browser with a blue neutral face that reveals and fades, like the green success check and red failure cross.

NEW — generate a starting pattern

NEW is the first entry in PATT. Select it and press load (encoder 1) to open the pattern generator. You can also reach it from an empty (dim blue) slot. It does not load a store; it invents notes with the same scale-aware generator as single-mode randomize, then parks the result in RAM.

Settings inside the pattern file

A numbered pattern is a binary file in the SD card root, such as 42.txt. Despite the extension, it is not editable text. It contains all pages, per-step values, sound settings, mutes and the 64-slot page arrangement. There is no separate .dat file or sidecar. With SUBP in use, A stays in 42.txt; companions 42-B.txt … 42-E.txt each store a complete pattern for that number. No 42-A.txt is created. FN switching changes only notes; PATT loading can also restore saved sound settings.

The sideload triangle means keep current filters/settings. It is OFF by default on every PATT slot, so a normal load restores the saved filters, effects, envelopes, synth settings and voice volumes. Turn encoder 3 on by hand for the selected slot to keep your current sounds. Moving to another slot resets it OFF. Notes, BPM, mutes and arrangement still load. Saving always includes the current settings; startup recovery restores the complete saved session.

Empty saves keep subpatterns. Saving blank notes never deletes a file. FN + Save asks DEL? / NO before deleting all A–E files of the selected number. If that is the loaded family, its live notes are cleared too; deleting another number leaves your live notes intact.

The pattern does not contain sample audio. Keep the matching kit and any custom samples on the card.

Autosave — session recovery

Pausing playback and successful sample loads request a save to autosaved.txt. Successful autosaves have a five-second cooldown, so closely spaced actions may not create another checkpoint. Autosave does not overwrite the numbered PATT slot.

At boot, the firmware loads that recovery file. Saves use a temporary file for their destination (autosaved.txt.tmp or 42.txt.tmp) and retain the previous generation as .bak. A valid destination takes priority; if it is missing or unreadable, a complete temporary file or backup can be recovered for that same destination. The old shared pattern.tmp is not automatically loaded because it does not identify its target slot.

ETC → RSET → ASAV removes the recovery file and its transaction files. FULL resets the session and writes an empty recovery file. Empty saves preserve blank grids. FN + Save opens DEL? / NO for the selected numbered family, including A–E and their recovery files. Turn encoder 4 to choose NO (cancel) or YES (confirm), then press encoder 4. Cancel returns to the originating browser with an animated blue face with a straight mouth.

Save, then switch off. The physical power switch does not perform an automatic shutdown save. Save important work to a numbered PATT slot; a power loss after the latest checkpoint loses later edits.

How patterns relate to kits

PATT saves notes and sound settings; KIT saves the sample audio used by voices 1–8. Save both when you have replaced or recorded samples and want to recreate the session. Loading a pattern does not reload its samples.

To recall an idea, load its matching KIT, then its PATT with the sideload triangle OFF. To remix it, load another kit before loading the pattern. Keep a note of which kit belongs to each numbered pattern.

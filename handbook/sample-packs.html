Sample kits

A KIT holds the samples assigned to the eight sample voices. This chapter explains the KIT screen, how kits interact with patterns, and the special status of kit 0.

What a KIT contains

The SD card holds up to 999 kit folders numbered 1–999. Each folder defines which audio file plays on each of the eight sample voices (channels 1–8) when you trigger a step. Switching kits replaces all eight voices in one motion — your pattern stays exactly the same, but the sound changes completely.

Only sample voices 1–8 are filled from a KIT. Synth voices 11, 13, and 14 are generated, not played from files, so they stay the same across kits. Rows 9, 10, and 12 are empty — no voice is assigned there.

Switching kits replaces eight voices at once. Your pattern still references "voice rows", but the underlying audio files change. Save to PATT first if you care about recall later — the kit change by itself is not a backup.

KIT 0 — the scratchpad

KIT 0 is special. Whenever you load a single sample into a voice through the sample browser, the new mapping is written into KIT 0 so it survives reboot even if you never explicitly save it. Treat KIT 0 as your scratchpad: the place where one-off custom voice assignments accumulate.

If you build a sound you like in KIT 0 and want to keep it long-term, select a numbered KIT slot and press encoder 2 to save the current eight samples there.

How kits live on the card

Each kit number maps to a numbered folder on the microSD card. The starter layout from SD card chapter includes:

  • 0/, 1/ … 999/ — one folder per kit number. Each folder holds the WAV files for sample voices 1 through 8 plus optional extras.
  • 1.txt, 2.txt, … in the card root — binary pattern files with their settings.
  • scheme.txt — colour palette state, written by the colour-scheme web tool.

On boot the firmware indexes the card and your kits show up in KIT. If the list looks stale after swapping the card, refreshing its contents offline, or transferring via the SD tool (card stays in the unit), run ETC → RSET → SD.

Conventions: the starter card uses kit folder numbers loosely by genre — low numbers for acoustic drums, mid-range for house/techno, higher for synth-only kits. Stick to the same naming when building new ones and the KIT screen becomes a quick set-list browser.
